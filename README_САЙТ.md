# Сайт Nova Scar — как устроен и что доделать (обновлено 31.10.2026)

## Структура

Сайт статический: HTML + CSS + JS, сервер для него не нужен. Открывается двойным кликом по `index.html` или с любого хостинга (GitHub Pages и т.п.).

| Файл | Что это |
|---|---|
| `index.html` | **Вход на сайт: выбор игры → выбор режима.** Garry's Mod (Mini City RP — работает, SCP RP — в разработке), Minecraft (NS-Deadzone + новый режим), CS 1.6, Roblox (режим в разработке; картинка `assets/roblox.jpg` — заглушка). Сайт помнит, где игрок был в прошлый раз. |
| `minicity.html` | Главная режима Mini City RP (бывшая `index.html`) |
| `about.html` | О сервере: структуры города, экономика с цифрами |
| `systems.html` | **Новое.** Возможности: клавиши, команды, все системы сервера со статусом (работает / бета-тест / в разработке), «Скоро на сервере» |
| `professions.html` | 34 профессии — тексты взяты прямо из игры (F4), плюс меню профессии и донат-доступ |
| `rules.html` | Правила: «Важно знать», законы города, наказания |
| `donate.html` | Статусы VIP / PREMIUM / LEGEND, платные профессии, магазин, красивые номера, сезон, как пополнить |
| `news.html` | Новости |
| `cabinet.html` | **Новое.** Личный кабинет |
| `projects.html` | Старый адрес — перекидывает на `index.html` |
| `deadzone/` | **Раздел NS-Deadzone (Minecraft)** — см. ниже |

| JS | Что внутри |
|---|---|
| `js/config.js` | **Главные настройки:** адрес сервера, ссылки (Discord, Workshop, оплата), игры и режимы, новости, адрес API кабинета, блок `deadzone` (серверы, лаунчер, Discord, цены, новости NS-Deadzone) |
| `js/professions-data.js` | Профессии, законы, экономика |

**Адреса без .html:** на сайте страницы открываются как `novaskar.com/minicity`, `/donate`, `/cabinet` (GitHub Pages сам находит `minicity.html`). Старые ссылки с `.html` тоже работают — строка адреса сама становится короткой. Если открыть сайт двойным кликом по файлу, ссылки тоже работают (app.js дописывает `.html`).

Шапка и подвал собираются скриптом `build.py` (лежит в `Claude Mini_City_RP\nova_site_src\`). Если правишь только тексты в `js/*.js` — пересобирать ничего не нужно.

## Частые правки

- **Второй режим Garry's Mod** — в `config.js`, `games → gmod → modes`, второй элемент (`name: "SCP RP"`). Когда режим запустится: `status: "live"` и `url` на его страницу.
- **Новость** — добавь объект в начало `news` в `config.js`.
- **Статус системы** («Бета-тест» → «Работает») — `status` в `systems-data.js`.
- **Цены доната** — `donate-data.js` (и не забудь `nova_donate/sh_config.lua` в игре).
- **Коллекция Workshop, VK, оплата** — `links` в `config.js`.
- **Онлайн на сайте** — найди сервер на battlemetrics.com и впиши его ID в `server.battlemetricsId`.

## Раздел NS-Deadzone (Minecraft) — добавлен 31.10.2026

Minecraft-проект переименован: LAST CITY → **NS-Deadzone** (Zombie Survival, Minecraft 1.21.1, свой лаунчер). Нигде не упоминаем, на какую игру это похоже. На стартовом экране у Minecraft два режима: NS-Deadzone (три одинаковых сервера ALPHA / DELTA / OMEGA — внутри раздела) и второй режим «город с военной базой, квесты, война кланов» (в разработке, название пока не выбрано — `config.js → games → minecraft → modes`). Кнопка «Скачать лаунчер» — под режимами.

Страницы раздела (папка `deadzone/`, адреса `novaskar.com/deadzone/…`): главная (`index.html`), `about` (о сервере), `systems` (возможности), `launcher` (лаунчер), `rules` (правила с наказаниями), `donate` (монеты и статусы), `news` (новости раздела, одна новость — `news?id=…`), `map` (карта), `wiki` (вики). Шапка и подвал раздела — в стиле сайта, акцент оранжевый; «Войти» и кабинет общие.

Что менять — всё в `js/config.js`, блок `deadzone`:
- `servers[]` — статус каждого сервера (`soon` → На старте, `online` → Работает с онлайном, `later` → Позже), адрес, свой Discord;
- `api` — адрес сервиса статуса (формат ответа в комментарии); пока пусто — онлайн «—»;
- `nextInvasion` — время ближайшего нашествия (таймер на главной раздела сам прибавляет 7 дней); слово «кровавая луна» не используем — у нас это «Нашествие»;
- `launcher` — ссылки на установщики, версия, дата, размер;
- `discord.invite` и `discord.widgetId` — Discord NS-Deadzone (у каждого проекта свой: `links.discord` — основной/Mini City);
- `donate` — донат как в Mini City RP: доллары ($), `rate` (1 $ = 10 000 игровых денег NS-Deadzone), суммы пополнения `packs`, цены статусов VIP $20/мес · $200 навсегда, PREMIUM $40 · $400, LEGEND $80 · $800 (`pricesFinal: true` убирает пометку «предварительные»);
- `news[]`, `team[]`, `socials[]`, `map`, `wiki`.
Тексты механик/правил/FAQ — `deadzone/js/dz-data.js` (черновики, сверить со сборкой). Картинки `deadzone/assets/*.jpg` — заглушки, заменять файлами с теми же именами; логотип NS-DEADZONE рисуется SVG-текстом (`<template id="logo-minecraft">` в `index.html` и `<svg class="dz-logo">` в `deadzone/index.html`).

Требует бэкенда (на сайте заглушки): оплата монет/статусов, живой онлайн и таймер (нужен сервис `api`), карта (BlueMap) и вики, автопубликация новостей в Discord. Вход через почту/Google/VK/Telegram/Discord — задача кабинета (бот).

## Личный кабинет

`cabinet.api` = `https://api.novaskar.com:25662` — это бот основного Discord на Sparked Host. В шапке на всех страницах — меню пользователя: кабинет, донат-баланс, сезон, игры и привязки, выход. Кнопка «Открыть пример кабинета» всегда показывает кабинет на демо-данных.

**Единый вход (с 31.10.2026).** Аккаунт Nova Scar один на все игры. Экран входа: кнопки Google / VK / Telegram / Discord, почта и пароль, ниже — «Войти кодом из игры». Код из Mini City RP — это подтверждение игрового аккаунта (раздел «Игры»), а не отдельный вход. Пока бот не умеет вход по почте и через соцсети, кнопки показывают «подключается», а войти можно кодом из игры — так аккаунт и создаётся. Что нужно доделать в боте и как включить — в `js/config.js` → `cabinet.auth` и в шапке `js/cabinet.js`:
- `POST /auth/login {email,password}`, `POST /auth/register {email,password,nick}`, `POST /auth/reset {email}` → `{ok, token, profile}`; включение — `cabinet.auth.email: true`;
- `GET /auth/google|vk|telegram|discord` — начало входа через соцсеть, в конце редирект на `https://novaskar.com/cabinet?token=…`; включение — адрес в `cabinet.auth.google` и т. д.;
- `POST /site/link {game:"gmod"|"minecraft", code}` → `{ok, profile}` — добавить игровой аккаунт кодом из игры; в `profile.games` бот отдаёт `{ gmod:{nick,steamid}, minecraft:{nick,uuid}, cs:null }`.
Пароли — только хешем (bcrypt/argon2); при входе с нового устройства — письмо; список сессий — уже есть («Выйти на всех устройствах»).

**Вход кодом из игры** работает для обеих игр: на экране входа переключатель Mini City RP / NS-Deadzone (`config.js → cabinet.codeGames`), в запрос уходит `game: "gmod" | "minecraft"`. Для NS-Deadzone бот должен принимать коды от Minecraft-сервера (команда `/site` в игре) — пока сервер не открыт, кнопка подписана «откроется вместе с сервером».

**Аккаунт создателя (предпросмотр).** Пока бот не умеет вход по почте, в `config.js → cabinet.owner` задан аккаунт владельца: почта + отпечаток пароля (SHA-256, сам пароль на сайте не хранится). Вход по нему открывает кабинет в браузере без сервера (пометка «Создатель»); игровые аккаунты подтверждаются кодом из игры уже внутри, и тогда данные идут с сервера. Поменять пароль: посчитать SHA-256 новой строки (например, на emn178.github.io/online-tools/sha256.html) и вставить в `hash`. Это только предпросмотр — никаких прав на сервере такой вход не даёт.

Разделы кабинета: Обзор (уровень, опыт, финансы, онлайн/профессия, донат — пока по Mini City RP), **Игры** (Mini City RP — подтверждён/подтвердить кодом; NS-Deadzone — после открытия сервера; CS 1.6 — позже), Донат (баланс, статус, подписки, история), Сезон, Квесты, Привязки (почта, игровые аккаунты, Discord, паспорт, телефон), Безопасность (выход, выход на всех устройствах).

### Как кабинет связывается с игрой

```
Игрок в игре: F4 → Настройки → «Сайт и личный кабинет» → «Получить код» (6 цифр, 10 минут)
        │  аддон nova_site добавляет код и снимок профиля в POST /nova/sync (nova_discord → бот)
        ▼
Сайт: игрок вводит код → POST https://api.novaskar.com:25662/site/login → бот выдаёт токен (30 дней)
        ▼
Сайт: GET /site/me → профиль (бот хранит последний снимок из игры), обновление раз в минуту
```

Состояние на 17.10.2026: аддон `nova_site` и патчи `nova_discord`/`nova_f4menu` — на MyArena; бот с `/site/*` и HTTPS — на Sparked Host.

### HTTPS (без Cloudflare)

Сайт на https может обращаться только к https-адресу. Cloudflare не используем: в РФ его замедляют. Бот сам получает сертификат Let's Encrypt для `api.novaskar.com` и продлевает его (файл бота `main/src/tls.js`). Один раз нужно:

1. Аккаунт на **desec.io** (бесплатный DNS) с доменом `<имя>.dedyn.io` и токен → вставить в первую строку `main/desec_token.txt` на Sparked Host → Save.
2. В DNS novaskar.com (Squarespace) две записи:
   - `A` · `api` → `45.43.163.175`
   - `CNAME` · `_acme-challenge.api` → `_acme-challenge.<имя>.dedyn.io`

Через пару минут в логе бота: `[HTTPS] Сертификат получен`. Проверка: https://api.novaskar.com:25662/site/status.

## Публикация

Сайт живёт на GitHub Pages: репозиторий **github.com/denic100x/novaskar-site** (ветка `main`, корень), домен **https://novaskar.com** (файл `CNAME`), HTTPS включён. Записи DNS в Squarespace: `A @` → 185.199.108.153 / .109.153 / .110.153 / .111.153, `CNAME www` → `denic100x.github.io`.

Обновить сайт: github.com/denic100x/novaskar-site → открыть папку → «Add file» → «Upload files» → перетащить изменённые файлы → «Commit changes». Через 1–2 минуты изменения на novaskar.com.
